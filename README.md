# DLSS 5 Bridge

**DLSS 5 Bridge** puts a DLSS 5 nvngx path into titles still on 3 / 4 / 4.5. Neural upscale and frame gen on the current driver. RenoDX and ReShade load after the bridge if you want them.

## How to use
1. Run as admin so it can see the game folder.
2. Pick the title.
3. Bridge. Launch. Set Quality / Performance in the game menu.
4. Optional: load RenoDX or ReShade after.

## FAQ

**How to enable?**
Bridge, then turn it on in the game menu.

**AMD?**
No native Tensor path. Bridge refuses.

**Is it AI?**
Neural rendering, not a sharpen slider.

## Requirements
